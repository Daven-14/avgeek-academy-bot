# Module diagrams

Place optional illustration images here. When a user opens a module home screen,
the bot sends the matching image (if present) with the module title as caption.

## Naming

Use the module `id` from the YAML files:

| File | Module |
| --- | --- |
| `aero.png` or `aero.jpg` | Aerodynamics basics |
| `struct.png` | Aircraft structures & materials |
| `prop.png` | Propulsion |
| `avion.png` | Avionics & flight instruments |
| `sys.png` | Flight controls & systems |
| `nav.png` | Navigation & ATC basics |
| `safe.png` | Safety, regs & emerging tech |

Supported extensions: `.png`, `.jpg`, `.jpeg`, `.webp`.

Images are optional. Free and Pro modules both support diagrams.
